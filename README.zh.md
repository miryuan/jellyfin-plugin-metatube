## 简介

MetaTube 是一款为 Jellyfin/Emby 开发的强大元数据插件。

## 功能特性

- 完整元数据：包括标题、简介、标签、导演、演员和工作室等丰富信息。
- 强大搜索：支持从多个数据源搜索影片和演员信息。
- 预告片功能：无需下载即可在线观看预告片视频。
- 定时任务：自动整理元数据标签并更新插件。
- 人脸识别：内置人脸识别引擎，自动以人脸为中心裁剪海报图片。
- 自动翻译：支持将特定元数据内容翻译为目标语言。
